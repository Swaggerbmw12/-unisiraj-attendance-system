# Attendance Reports - Quick Reference Guide

## 📊 What Reports Can I Generate?

### 1. Course Summary Report
**Best for:** Overall course performance at a glance

**Shows you:**
- ✅ Total sessions conducted
- ✅ Overall attendance rate
- ✅ Session-by-session breakdown
- ✅ Student rankings by attendance
- ✅ At-risk students (below 50%)

**When to use:**
- End of semester review
- Department meetings
- Performance assessments
- Quick course health check

---

### 2. Student Details Report
**Best for:** Individual student tracking

**Shows you:**
- ✅ Each student's attendance record
- ✅ Exact dates/times they attended
- ✅ Email addresses for contact
- ✅ Performance status (Excellent/Fair/At Risk)
- ✅ Percentage calculations

**When to use:**
- Academic advising
- Identifying struggling students
- Parent-teacher conferences
- Student progress reports

---

### 3. Session Details Report
**Best for:** Verifying specific session attendance

**Shows you:**
- ✅ Who attended each session
- ✅ Exact check-in times
- ✅ Session date and duration
- ✅ First/last check-in statistics
- ✅ Complete attendance lists

**When to use:**
- Attendance disputes
- Grade calculation
- Session-specific analysis
- Audit requirements

---

## 🚀 How to Generate a Report

### Step 1: Access Reports
```
Lecturer Dashboard → Click "Reports" button
```
OR
```
Click "Reports" in the top navigation menu
```

### Step 2: Choose Report Type
Select one of three options:
- ⭕ Course Summary (recommended for overview)
- ⭕ Student Details (for individual tracking)
- ⭕ Session Details (for specific sessions)

### Step 3: Select Course
Choose from dropdown:
```
[Select a course ▼]
↓
BOT4423/BTT3134 - Software Engineering
CS401 - Database Systems
etc.
```

### Step 4: Set Date Range (Optional)
**Leave empty for ALL dates**, or specify:
```
Date From: [2026-09-01] 
Date To:   [2026-09-30]
```
**Tip:** Use date range to focus on specific periods (e.g., mid-semester)

### Step 5: Choose Output Format
- 🖥️ **View Online** (default) - View in browser, can print
- 📄 **PDF Document** (coming soon)
- 📊 **Excel/CSV** (coming soon)

### Step 6: Generate
Click the big blue button:
```
[📈 Generate Report]
```

## 🖨️ Printing Your Report

### Method 1: Print Button
1. Click **"Print Report"** button (top right)
2. Select your printer
3. Adjust print settings if needed
4. Click "Print"

### Method 2: Save as PDF
1. Click **"Print Report"** button
2. Choose **"Save as PDF"** as printer
3. Select destination folder
4. Click "Save"

**✨ Print Features:**
- Professional header with course info
- Date range and generation time
- Clean layout without navigation
- Optimized for A4/Letter paper

## 📈 Understanding the Data

### Attendance Percentages

**Color Coding:**
- 🟢 **Green (75-100%):** Excellent attendance
- 🟡 **Yellow (50-74%):** Fair attendance, monitor
- 🔴 **Red (0-49%):** At risk, needs intervention

### Student Status Labels

| Percentage | Status | Action Needed |
|------------|--------|---------------|
| ≥75% | ✅ Excellent | Keep it up! |
| 50-74% | ⚠️ Fair | Encourage improvement |
| <50% | ❌ At Risk | **Immediate attention required** |

## 💡 Pro Tips

### Tip 1: Regular Monitoring
Generate **Course Summary** report weekly to spot trends early

### Tip 2: Date Range Strategy
- **Weekly reports:** Last 7 days
- **Monthly reports:** Current month
- **Semester reports:** Leave dates empty (all data)

### Tip 3: At-Risk Student Action
When **Student Details** shows red status:
1. Generate detailed report
2. Contact student via email (shown in report)
3. Offer support/resources
4. Follow up next week

### Tip 4: Session Verification
Use **Session Details** when:
- Student claims they attended but system says no
- Need to verify exact check-in time
- Resolving grade disputes

### Tip 5: Print vs Digital
- **Print:** Department meetings, official records
- **Digital:** Quick checks, email sharing

## 🎯 Common Use Cases

### Use Case 1: Mid-Semester Assessment
**Goal:** Identify struggling students

1. Generate **Student Details Report**
2. Filter for current semester (set date range)
3. Look for students below 75%
4. Contact those students
5. Offer intervention

### Use Case 2: End of Semester Grades
**Goal:** Calculate participation grades

1. Generate **Course Summary Report**
2. Export to Excel (when available)
3. Import attendance percentages to gradebook
4. Apply weighting formula

### Use Case 3: Attendance Dispute
**Goal:** Verify student's claim

1. Generate **Session Details Report**
2. Find the specific session in question
3. Check attendance list
4. Show timestamp as proof

### Use Case 4: Department Reporting
**Goal:** Present course performance

1. Generate **Course Summary Report**
2. Print or save as PDF
3. Highlight key metrics:
   - Average attendance rate
   - Number of sessions
   - At-risk student count

## ❓ Troubleshooting

### Issue: "No sessions found"
**Causes:**
- Date range too narrow
- No sessions created yet
- Wrong course selected

**Solution:**
- Remove date filters (leave empty)
- Verify course has sessions
- Check session creation

### Issue: "No students in report"
**Causes:**
- No enrollments in course
- No attendance recorded yet
- Date range excludes all activity

**Solution:**
- Verify students are enrolled
- Check if attendance has been taken
- Widen date range

### Issue: Report looks wrong when printing
**Solution:**
- Use "Print Report" button, not browser Ctrl+P
- Check print preview before printing
- Adjust page margins if needed

### Issue: Can't access reports
**Causes:**
- Not logged in as lecturer/admin
- Session expired
- Insufficient permissions

**Solution:**
- Log in with lecturer/admin account
- Refresh and log in again
- Contact system admin
