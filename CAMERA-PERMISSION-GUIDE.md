# Camera Permission Guide for Students

## 📱 How to Enable Camera for QR Scanning

### For Mobile Browsers

#### Chrome (Android)
1. Open the attendance scan page
2. Click "Start Camera"
3. Browser shows: **"Allow domain.com to access your camera?"**
4. Tap **"Allow"** or **"While using the app"**
5. Camera activates and you can scan

**If Blocked:**
1. Tap the padlock icon in address bar
2. Tap "Site settings"
3. Find "Camera"
4. Change to "Allow"
5. Refresh page and try again

#### Safari (iOS)
1. Open the attendance scan page
2. Click "Start Camera"
3. Browser shows: **"domain.com Would Like to Access the Camera"**
4. Tap **"Allow"**
5. Camera activates

**If Blocked:**
1. Open iPhone Settings
2. Scroll to Safari
3. Tap "Camera"
4. Select "Ask" or "Allow"
5. Return to browser and refresh

#### Firefox (Android)
1. Open the attendance scan page
2. Click "Start Camera"
3. Browser shows permission prompt
4. Tap **"Allow"**
5. Camera activates

**If Blocked:**
1. Tap menu (three dots)
2. Tap "Settings"
3. Tap "Site permissions"
4. Tap "Camera"
5. Find the site and change to "Allow"

### For Desktop Browsers

#### Chrome (Desktop)
1. Click "Start Camera"
2. Address bar shows camera icon with "blocked" or "prompt"
3. Click the camera icon
4. Select "Always allow"
5. Click "Done"

**If Blocked:**
1. Click padlock/camera icon in address bar
2. Find "Camera" setting
3. Change to "Allow"
4. Reload page

#### Firefox (Desktop)
1. Click "Start Camera"
2. Dropdown appears below address bar
3. Select camera device
4. Click "Allow"
5. Check "Remember this decision" (optional)

#### Edge (Desktop)
1. Click "Start Camera"
2. Permission prompt appears
3. Click "Allow"
4. Camera activates

#### Safari (macOS)
1. Click "Start Camera"
2. Browser asks for permission
3. Click "Allow"
4. Camera activates

**If Blocked:**
1. Safari > Settings > Websites
2. Select "Camera"
3. Find the site
4. Change to "Allow"

## 🔒 Privacy & Security

### What We Access
✅ Camera feed for QR code scanning only
✅ No video recording
✅ No image storage
✅ Camera stops after scan

### What We Don't Do
❌ Record video
❌ Take photos
❌ Store camera data
❌ Access camera without permission
❌ Use camera in background

### Your Control
- Permission required every time (or saved if you choose)
- Can revoke anytime through browser settings
- Camera indicator shows when active (dot/icon)
- Camera stops when you close tab

## 🚨 Troubleshooting

### Camera Permission Denied
**Symptom:** Alert says "Unable to access camera"

**Solution:**
1. Follow "If Blocked" steps for your browser above
2. Refresh the page
3. Click "Start Camera" again
4. Or use manual entry instead

### Camera Shows Black Screen
**Possible Causes:**
- Another app is using the camera
- Camera hardware issue
- Browser needs restart

**Solutions:**
1. Close other apps using camera
2. Restart browser
3. Restart device
4. Try different browser
5. Use manual entry

### Wrong Camera Activates
**Symptom:** Front camera instead of back

**Solution:**
- System uses back camera by default
- If only front camera available, use mirror mode
- Flip device to show QR code to front camera

### QR Code Not Detected
**Solutions:**
- Ensure good lighting
- Hold device steady
- Move closer (but not too close)
- Ensure QR code is clear and in focus
- Try manual entry if scanning fails

### "Camera Not Supported" Error
**Causes:**
- Using HTTP instead of HTTPS
- Very old browser version
- Device doesn't have camera

**Solutions:**
1. Ensure using HTTPS URL
2. Update browser
3. Use manual token entry

   - Safari

   - Explain the exact error message

## 🎯 Quick Start

### First Time Using Scanner

1. **Open Scan Page**
   - Login as student
   - Navigate to "Scan QR Code"
   - Or tap QR code link from lecturer

2. **Allow Camera**
   - Tap "Start Camera"
   - Tap "Allow" when prompted
   - Wait for camera to activate

3. **Scan QR Code**
   - Point camera at lecturer's screen
   - Hold steady
   - Wait 1-2 seconds
   - Automatic submission

4. **Verify Attendance**
   - Check success message
   - View attendance history
   - Confirm with lecturer

### Subsequent Uses

If you selected "Remember this decision":
1. Tap "Start Camera"
2. Camera activates immediately (no prompt)
3. Scan and done!
